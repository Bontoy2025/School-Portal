# Rules

## Development Rules
1. Keep the project simple, clean, and readable.
2. Use semantic HTML and structured CSS.
3. Maintain consistent naming conventions.
4. Avoid hardcoded logic in multiple places.
5. Prefer reusable components and patterns.

## UI Rules
- Use a clear hierarchy for headings and buttons
- Keep spacing consistent
- Ensure forms are readable on mobile devices
- Use accessible labels and contrast-friendly colors

## Project Rules
- All major features should be documented
- Use the docs folder for planning and requirements
- Keep commits clear and intentional
- Test the app after changes

## Role Rules
- Teacher: class and academic management
- Parents: student monitoring and communication
- Admin: full oversight and system management

## Security Rules
- Never store passwords in plain text in the frontend
- Use secure backend authentication in production
- Validate all user input
