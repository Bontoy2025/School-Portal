# Memory

## Project Context
This repository is a School Portal project with multiple roles: Teacher, Parents, and Admin.

## Key Decisions
- Role-based access is a core requirement
- Initial implementation focuses on frontend UI and forms
- Documentation will be maintained in the docs folder
- The app should later be connected to a real backend and database

## Current Status
The project currently includes a landing page with sign-in and sign-up functionality for the three user groups.

## Notes
- The project is easy to extend because the user flow is role-driven.
- The design system is intentionally simple and clean.
- Future iterations should include dashboards and data integration.

## Next Milestones
1. Build role-specific dashboard pages
2. Connect authentication flow to backend
3. Add school data management modules
4. Expand into a full school management platform
