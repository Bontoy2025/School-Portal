# Design

## Design Goals
- Modern and professional
- Easy for all user groups to understand
- Mobile-friendly and responsive
- Consistent visual hierarchy

## Visual Style
- Main colors: blues, whites, and soft teal accents
- Rounded card layout
- Clear buttons for primary actions
- Strong contrast for accessibility

## Layout System
- Centered content container
- Two-column form layout on larger screens
- Single-column stacking on smaller screens

## Components
- Header with portal branding
- Role switcher buttons
- Sign-in form
- Sign-up form
- Status messages for feedback

## Typography
- Clean sans-serif system fonts
- Bold labels and readable form fields
- Comfortable spacing for readability

## Recommended Improvements
- Add icons to role cards
- Add illustrations or hero section
- Create a dashboard design for each role
- Introduce an onboarding flow
